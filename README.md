# hxyfront-62011 马术蹄铁修整档案

源提示词编号：6

面向马术俱乐部蹄铁师的修蹄档案台前端：从马匹列表进入单马档案，分别登记四蹄（左前/右前/左后/右后）的形态、蹄铁类型与钉位，自动判定复查，保存本地，刷新不丢。

## 功能

- **马匹档案**：马匹列表、编号/马名/用途检索，可新增马匹；点卡片进入该马档案。
- **四蹄对比登记**：每个蹄位独立登记形态评估、蹄铁类型、钉位，支持一键同步四蹄；前/后蹄左右形态实时对比，不一致即时标红。
- **步态问题**：勾选「步态异常」后必须填写问题描述。
- **自动复查提醒**：任一步态异常，或任意一对左右蹄形态评估不一致，记录自动进入复查队列并强制填写下次复查日期；正常记录不占提醒名额。
- **复查闭环**：待复查记录可「去复查」，复查结论不填写不能完成本次记录；复查提交后自动关闭原提醒。
- **蹄铁更换历史**：同一蹄位相邻记录蹄铁类型变化时自动生成更换流水。
- **照片备注**：登记时可写，也可在历史记录中随时后补。
- **筛选**：列表与马档案时间线支持「待复查」「异常步态」筛选，另支持运动马/休养马与关键词。
- **本地持久化**：所有档案保存在浏览器 localStorage（键 `farrier-archive-v1`），重新打开页面仍在；提供「重置示例数据」。

React 19 + Vite + TypeScript，无额外运行时依赖。
